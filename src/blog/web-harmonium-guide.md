## Welcome to Web Harmonium

Web Harmonium is a free, open-source virtual harmonium that runs entirely in your browser. Whether you're a seasoned harmonium player or picking one up for the first time, this guide will help you make the most of the tool.

## Quick Start

No setup required. Just visit [webharmonium.site](/) and start playing. The harmonium loads automatically and is ready to use within seconds.

## Interface Overview

The Web Harmonium interface has three main areas:

1. **Keyboard display** — A visual keyboard that lights up as you play
2. **Controls panel** — Adjust reverb, transpose, octave, and reed settings
3. **Navigation** — Access different sections of the site

## Keyboard Mapping

Your computer keyboard is mapped to harmonium notes in an intuitive layout:

| Key | Note | Indian Notation |
|-----|------|-----------------|
| A | C | Sa |
| S | D | Re |
| D | E | Ga |
| F | F | Ma |
| G | G | Pa |
| H | A | Dha |
| J | B | Ni |
| K | C (high) | Sa |

Sharp notes are played using the number row keys above the letter keys.

## Control Settings

### Reverb

Toggle reverb on or off. When enabled, it adds a natural room ambience to the sound, making it feel like you're playing in a concert space.

### Transpose

Shift the pitch up or down by semitones. Range: -12 to +12 semitones. This is equivalent to changing the scale on a physical harmonium.

### Octave

Select which octave to play in. You can choose from multiple octaves to access higher or lower registers.

### Reed Stack

Control how many reeds sound simultaneously:

- **1 reed** — Clean, simple tone
- **2 reeds** — Fuller sound with slight detuning
- **3 reeds** — Rich, powerful tone similar to a professional harmonium

## MIDI Support

Web Harmonium supports external MIDI controllers for a more authentic playing experience:

- **Auto-detection** — MIDI devices are detected automatically when connected
- **Full velocity sensitivity** — Play harder for louder notes
- **All controllers supported** — Works with any class-compliant USB MIDI keyboard

## Works Offline

After your first visit, Web Harmonium is cached as a Progressive Web App (PWA). This means:

- You can play without an internet connection
- The app loads instantly on subsequent visits
- It works like a native app on your device

## Browser Compatibility

Web Harmonium works on all modern browsers:

- Chrome (recommended)
- Firefox
- Safari
- Edge

For the best audio experience, we recommend using Chrome, as it has the most mature Web Audio API implementation.
